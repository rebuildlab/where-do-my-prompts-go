Self-Deployment
Self-Deployment
Choose an inference engine or infrastructure tool, such as vLLM, TensorRT-LLM, TGI or SkyPilot, to self-deploy Mistral models.
Mistral AI models can be
self-deployed on your own infrastructure
through various
inference engines. We recommend using
vLLM
, a
highly-optimized Python-only serving framework which can expose an OpenAI-compatible
API.
Other inference engine alternatives include
TensorRT-LLM
and
TGI
.
You can also leverage specific tools to facilitate infrastructure management, such as
SkyPilot
or
Cerebrium
.
For full-stack enterprise deployment, from efficient model inference to team management, we recommend
reaching out to us
.
Deployment guides
Pick an inference engine or an infrastructure tool to deploy Mistral models.
vLLM
vLLM
Install vLLM and run Mistral models locally in offline or server mode, or deploy them with Docker using a Hugging Face token.
TensorRT
TensorRT
Build a TensorRT-LLM engine for a Mistral model and deploy it with the Triton inference server and its TensorRT-LLM backend.
Deploy with SkyPilot
Deploy with SkyPilot
Write a SkyPilot configuration to deploy a Mistral inference server on any cloud with the pre-built Docker container, then test it.
Deploy with Cerebrium
Deploy with Cerebrium
Set up a Cerebrium project, configure its environment and GPU hardware, and run a Mistral model on serverless GPUs.
Deploy with Cloudflare Workers AI
Deploy with Cloudflare Workers AI
Set up Cloudflare Workers AI to run Mistral models on serverless GPUs across the Cloudflare global network.
Text Generation Inference
Text Generation Inference
Deploy Mistral models with the Text Generation Inference Docker container and query them through chat or generate endpoints.
