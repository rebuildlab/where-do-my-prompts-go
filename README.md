# Where Do My Prompts Go?

A sourced tracker of how AI tools handle your data: training defaults, retention,
zero data retention, abuse-monitoring exceptions, regions (Singapore/APAC called out),
SOC 2 / ISO 27001, HIPAA BAAs and self-host options.

Every field in `data/vendors.json` has `value`, `detail`, `quote`, `source` and `checked`.
If an official page didn't clearly say it, the value is `unverified`.

Live site: https://rebuildlab.github.io/where-do-my-prompts-go

## Layout

```
data/vendors.json            source of truth (one record per tool)
data/changelog.json          confirmed policy changes shown on /changelog/ (empty for now)
scripts/build.py             static site generator (stdlib only) -> public/ (incl. llms.txt)
scripts/export_hf.py         flat CSV/JSONL + dataset card -> hf-dataset/
scripts/check_policies.py    nightly fetch + snapshot + diff -> changes/YYYY-MM-DD.md
scripts/checker_config.json  noise filters and extra URLs for the checker
site/assets/                 style.css, app.js (copied into public/assets)
snapshots/                   main-text snapshot per source URL + index.json
changes/                     diff reports, one file per day with changes
public/                      built site (generated; safe to delete)
hf-dataset/                  Hugging Face dataset export (generated by export_hf.py)
.github/workflows/check-policies.yml   nightly run of the checker
.github/workflows/deploy-pages.yml     build public/ and deploy GitHub Pages
```

## Build and preview

```
python3 scripts/build.py
python3 -m http.server 8080 --directory public   # keeps working across rebuilds
```

The published site lives under `/where-do-my-prompts-go/`. Set `SITE_URL` so canonical
links, `sitemap.xml` and `llms.txt` use that path. `CONTACT_URL` is optional and adds
a corrections link on the Method page.

```
SITE_URL=https://rebuildlab.github.io/where-do-my-prompts-go python3 scripts/build.py
```

`public/` is gitignored and built in CI. `.github/workflows/deploy-pages.yml` publishes
it on every push to `main`, on manual dispatch, and after the nightly policy check
succeeds. That workflow commits with `GITHUB_TOKEN`, and those commits do not trigger
`push` workflows.

## Hugging Face export

```
python3 scripts/export_hf.py                      # rewrites hf-dataset/
SITE_URL=https://example.com python3 scripts/export_hf.py   # real site link in the card
```

One row per tool + field: value, status (verified/unverified), detail, source_url,
quote, checked_date. Run it after every change to `data/vendors.json`.

## Policy checker

```
pip install -r requirements.txt
python3 scripts/check_policies.py              # all sources
python3 scripts/check_policies.py --only anthropic.com
python3 scripts/check_policies.py --dry-run    # report only, write nothing
```

A diff means "re-read the page", not "the fact changed". Update `data/vendors.json`
and add an entry to `data/changelog.json` only after checking.

Known gaps: openai.com returns 403 to scripted requests; trust.mistral.ai renders
client-side only; AWS pages failed TLS from the build box (they load fine in a
browser). These keep their last snapshot (or none) and are listed in each report.
